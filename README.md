# Clinic Management System

Консольное приложение на Python для управления данными медицинской клиники.  
Поддерживает пациентов, врачей, персонал, отделения, назначения, счета, страховки, медицинские записи, рецепты и планы лечения.  
Сохранение и загрузка данных выполняются в форматах JSON и XML.

## Стек

- Python 3.6+
- Стандартные библиотеки: `json`, `xml.etree.ElementTree`, `typing`
- Без внешних зависимостей

## Структура

```text
clinic-management-system/
├── main.py            # основной модуль со всей бизнес-логикой
└── README.md
```

# Возможности

- CRUD-операции для пациентов, врачей, персонала, отделений, страховок, назначений и счетов
- Добавление медицинских записей, рецептов и планов лечения к пациенту
- Связь врачей с отделениями
- Выставление и изменение счетов
- Сохранение всей клиники в JSON или XML
- Загрузка данных из JSON или XML с восстановлением всех связей
- Встроенный демонстрационный пример (модуль можно запустить напрямую)

# Быстрый запуск

Клонируйте репозиторий и выполните скрипт:

```bash
git clone https://github.com/Zergloin/Lab1_Policlinic.git
cd Lab1_Policlinic
python main.py
```

После выполнения в папке проекта появятся файлы `clinic_data.json` и `clinic_data.xml`, а в консоль будет выведена демонстрационная информация (пациенты, персонал, отделения и т.д.).

# Основные классы

| Класс | Назначение |
|---|---|
| `Clinic` | Центральный класс, управляет всеми сущностями |
| `Patient` | Пациент, связан со страховкой, записями, рецептами |
| `Doctor` | Врач с указанием специальности |
| `Staff` | Сотрудник (не врач), например медсестра |
| `Department` | Отделение, содержит врачей |
| `Appointment` | Назначение приёма (пациент, врач, дата, время) |
| `Bill` | Счёт, выставленный пациенту |
| `Insurance` | Страховой полис (поставщик, номер) |
| `MedicalRecord` | Медицинская запись (диагноз, лечение) |
| `Prescription` | Рецепт на лекарство |
| `TreatmentPlan` | План лечения (диагноз и список шагов) |
| `DataStorage` | Абстрактное хранилище |
| `JsonDataStorage` | Сохранение/загрузка в JSON |
| `XmlDataStorage` | Сохранение/загрузка в XML |
